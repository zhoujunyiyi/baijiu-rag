# 白酒财报问答知识库

人工智能与数据分析 · 作业 3 · 方向 A

以 13 家上市白酒公司的 2024 年年度报告全文为语料。页面支持自由提问、同口径指标比较和原文摘录，每条引证链接到官方 PDF 页码，并显示章节和块编号。可展开查看该问题实际召回的块及分值。

## 复现

需要 Python 3.10–3.13、curl，以及能访问巨潮资讯和深交所的网络。首次建库需要下载公开年报。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python build.py --jobs 4
python app.py
```

打开 http://127.0.0.1:8765 。Windows PowerShell 可用 `.venv\Scripts\Activate.ps1` 激活虚拟环境，并确保 PATH 上有 curl。内存较小的电脑可设 `--jobs 1`。建库沿用已有 `data/pdf/`，索引生成后可离线运行问答。页面上的官方原文链接需要联网。

## 语料和索引

- [官方财报清单](reports.json) 记录公司、证券代码、完整 PDF URL。下载脚本会检查每份报告的页数。[建库清单](corpus-manifest.json) 记录本次语料的页数、文件 SHA-256、块数及表格行数。
- 正文按 PDF 物理页切分。表格按坐标恢复行列，保留表头、空单元格与可识别单位。对公司简介中的年度摘要表，用版面行补充恢复因折行分散的指标名称。每块保存公司代码、章节、PDF 页码和唯一块编号。
- 关键词侧为中文单字、双字与英文/数字词元的 BM25 倒排索引。向量侧把带 IDF 的哈希词向量投影到从语料学习的 112 维潜在语义空间，以余弦相似度取候选。两路使用倒数排名融合，年度数值题加权明确的年度财务表格行。
- 有公司名和年度指标名的问题按公司和指标分别检索，以原表中本期数值作答，单位一致时可排名。经营问答从召回块筛选原句。该实现全程本地运行，无需模型账户或 API 密钥。
- 多级表头、跨页延续和无边框财务表仍可能出现列标题缺失或跨行错位。叙述回答依赖词面重合和有限的摘录长度，清单型及多步骤问题可能漏答。引用的页码是从 PDF 封面开始计数的位置。

## 评测

```bash
python evaluate.py
```

- [评测题与参考答案](questions.json) 按官方年报原页核对，含 10 道题和 2 道跨公司全景题。
- [逐题评测](evaluation.md) 记录系统回答、出处、召回块编号、判定与失误原因。
- [完整召回记录](evaluation.json) 保留每题每组召回原文、公司、章节、页码、BM25、向量余弦、融合分值和各要点命中情况。同一题不同检索组可能召回同一块。
